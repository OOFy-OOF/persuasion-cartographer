    About this tool's perspective

    This tool is not neutral. It was built to make persuasion visible, not to decide what is true. No neutrality doesn't mean all claims are equal; it means the choice of which claims to compare is itself a rhetorical act, and this tool says so out loud.

    It does not assess factual accuracy, authorial intent, or moral character. It does not label anything "propaganda." It quotes, names techniques, and explains how they work.

    Abstention is a valid and common result. When the tool cannot ground a claim in an exact quote, it says so.

    Use this map as a starting point for your own reading, not as a conclusion.

    Chrome extension

    Take the cartographer with you

    Select text on a webpage, right-click, and choose Analyze Rhetoric to open a full analysis. Or use the extension button to analyze selected or pasted text in a popup.

    Download extension (.zip)

    Set it up in Chrome

    1. Download and extract the ZIP file to a folder you can keep.
    2. Open chrome://extensions in Chrome and turn on Developer mode.
    3. Choose Load unpacked and select the extracted extension folder.
    4. Select text on a webpage, right-click it, and choose Analyze Rhetoric.

    If you update the extension, return to chrome://extensions and press its reload icon. Chrome blocks extensions on some internal pages, such as the Chrome Web Store.
