    Chromium browser extension

    Take the cartographer with you

    Analyse selected webpage text from the right-click menu, or open the popup and paste text. The extension uses the browser's plain-text selection; it doesn't capture images.

    Download extension (.zip)

    Install and connect

    1. Download and extract the ZIP file to a folder you can keep.
    2. Open your browser's extensions page (for example, chrome://extensions in Chrome, Edge, or Brave) and turn on Developer mode.
    3. Choose Load unpacked and select the extracted extension folder.
    4. Click the gear icon in the top-right of the extension popup to open Configure API endpoint. Enter the full HTTPS URL for your deployment, ending in /analyze (for example, https://your-domain.example/analyze), then grant access to that host. HTTP is supported only for localhost development.
    5. Select webpage text and right-click Analyse Rhetoric. The popup opens with the selection ready. You can also open the popup directly and paste text.

    Requires a Chromium-based browser version 127 or later. Tested explicitly on Microsoft Edge. If the browser was open during installation or an update, reload the extension from its extensions page. Browser restrictions may prevent it from working on internal or store pages; paste text into the popup on those pages.

    Only selected text is sent for analysis, and context-menu selection is held temporarily in browser session storage until the popup reads it.

    About this tool's perspective

    This tool is explicitly not "neutral." We reject the centrist myth that "balance" means treating all claims as equally valid—a framing that often functions to manufacture consent for the status quo. Instead, this tool makes the machinery of persuasion visible, exposing how language is used to shape public perception and protect institutional power.

    It does not assess factual accuracy, nor does it judge moral character. It does not explicitly label anything "propaganda." Instead, it isolates the exact evidence, names the technique, and explains the mechanism, handing the tools of critical analysis back to the reader.

    Abstention is used when there is too little content or context to examine, or when no rhetorical technique can be supported by an exact quote. A very short standalone preference such as “I don't like apples” gives no reasoning or rhetorical framing to map; a concise but clear rhetorical tactic should still be identified. Satire, copypastas, strong opinions, neutral reporting, and quoted rhetoric are still examined; when no clear technique is present, the tool abstains rather than forcing a label.

    Use this map as a starting point for your own structural critique, not as a conclusion.
